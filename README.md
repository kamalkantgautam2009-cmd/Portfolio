# Kamal Kant Gautam — Portfolio · Edition 05

A responsive, metallic editorial portfolio built with plain HTML, CSS and JavaScript. No build step or framework is required.

## Run locally
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html` with Live Server, or open it directly in a browser.

## What is included
- Interactive hero identity card and hanging lamp theme switch.
- Five interactive doors with project and skill details.
- Four expandable project panels: Because Credit Matters, KisanSetu, VisiDrop and Bad UI.
- About slider, skills explorer and draggable achievement carousel.
- Responsive six-chapter journey timeline with expandable details.
- Contact section and the LinkedIn profile URL supplied by Kamal.
- Custom SVG favicon and responsive layouts for desktop, tablet and mobile.
- Original profile photograph integrated at `assets/kamal-photo.jpg`.
- Brushed-silver metallic styling, improved light/dark theme consistency and persisted theme preference.

## Notes before publishing
- Confirm the dates, awards and project descriptions are accurate and public.
- Confirm the email address and GitHub profile shown in the contact section.
- The contact form opens the visitor's email application; it does not submit to a server.
- The site uses Google Fonts when internet access is available and falls back to system fonts otherwise.
